# 01 · 阿里云购买、实名认证与学生认证

适用目标：先拿到一台能长期运行QQ和Python服务的Ubuntu服务器，再进行软件部署。本文不替你提交认证材料或付款。界面可能改版，按钮名称和权益以当前官方页面为准。核对日期：2026-11-12。

## 1. 准备一个自己长期使用的阿里云账号

从[阿里云官网](https://www.aliyun.com/)注册或登录，先在账号中心确认登录账号和绑定联系方式。实名认证和学生认证应使用自己的真实身份；不要购买、借用或公开他人的学生账号。

进入账号中心的实名认证入口，选择个人认证，按官方页面提供的方法完成核验。企业认证与学生个人权益不是同一流程。认证中出现的身份证、支付宝授权信息和验证码只在官方页面填写，不要写入仓库、Issue或聊天机器人配置。

完成后返回账号中心，确认“个人实名认证”状态已通过，再进入学生验证。

## 2. 完成学生身份验证

官方步骤：[学生身份验证](https://help.aliyun.com/zh/account/student-identity-verification)。

从账号中心找到学生验证入口，也可从[高校用云支持计划](https://university.aliyun.com/)的学生申请入口进入。通常由手机支付宝扫码，确认与阿里云个人实名身份一致，再按提示授权核验学籍。以页面返回的结果为准，不要只凭扫码完成判断成功。

回到阿里云页面确认学生身份已通过；若扫码过期，重新打开当前验证页生成新的二维码。未通过时，按照官方说明检查实名身份是否一致、学籍是否在支持范围；无法自动核验的情况走官方支持流程，不反复更换身份尝试。

## 3. 领取并核对代金券

进入[学生用券中心](https://university.aliyun.com/buycenter)。认证成功不等于券已到账，按页面完成领取，再到优惠券/权益记录查看状态。

领取后至少核对：券金额、有效期、支持商品、抵扣次数、是否能与当前折扣同用。当前官方权益页展示学生专属300元券，但活动和适用商品会调整；本文不承诺任何规格、期限都能0元购买。

不要为了“把券用完”先随便买一个订单。若规则限制同类商品抵扣一次，误用可能影响真正想买的服务器。

## 4. 选服务器

从用券中心进入支持的云服务器或轻量应用服务器商品，优先核对能否用券，再比较规格。

| 选项 | 本项目的选择思路 |
|---|---|
| 产品 | 初学者可选轻量应用服务器；ECS也可，安全组入口不同 |
| 地域 | 选择你使用方便、具备合适网络条件的地域；创建后通常不直接改地域 |
| 系统 | Ubuntu 24.04 LTS，系统镜像；不要误选WordPress等应用镜像 |
| CPU/内存 | 2核2GB可用于本项目；QQ和进程较多时要观察剩余内存 |
| 架构 | x86_64更便于对照本教程；ARM要下载匹配的QQ/NapCat组件 |
| 磁盘 | 约40GB起可作为示例；关注QQ日志和缓存增长 |
| 公网与流量 | 确认含公网访问能力及流量额度，了解超额规则 |
| 购买时长 | 比较实际应付金额；不要只看标题上的月均价 |

这不是深度学习训练服务器选型。本项目通过API调用DeepSeek，无需GPU。

## 5. 结算前检查与付款

在订单页面逐项确认：商品规格、地域、镜像、时长、原价、用券抵扣、最终实付、自动续费状态和到期日期。只有最终实付显示0元，才能认为该订单本次没有现金支出；“领了300元券”不代表任意订单都是0元。

确认你理解订单后，由你在官方页面完成协议确认和付款。不要在本仓库留下订单号、付款记录或个人账单截图。

购买后在控制台查看实例状态为运行中，记录自己的公网IP、登录用户名和到期时间到私密位置。检查是否意外创建了重复实例、额外磁盘或额外付费服务。

## 6. 登录与初始网络

在轻量控制台使用远程连接/Workbench免密登录，也可配置SSH密钥后从自己的终端连接。Ubuntu默认用户名可能由产品镜像决定，以控制台展示为准；不要照抄别人教程的root密码。

```bash
whoami
uname -m
lsb_release -ds
free -h
df -h /
```

核对系统、架构、内存和磁盘后进入[完整部署](02-deployment.md)。

公网入站通常只需SSH管理端口，且尽量限定来源。3000、6099、8765均设计为服务器本机端口，不需要在云防火墙开放。

## 7. 到期和续费

部署完成后记录服务器到期日、代金券到期日、自动续费开关，以及流量用量查看入口。续费价格可能不同于首购价，券也不一定能再次使用。学生身份认证的有效期和券的有效期是两回事，都以各自官方页面为准。

停止机器人进程不等于停止云服务器计费；关机也不必然停止所有资源费用。需要停用时先备份，再按具体产品账单和释放规则处理。服务器实例释放会影响磁盘数据，先确认备份完整。

## 完成标志

- 个人实名、学生验证状态与已领取权益均已核对。
- 服务器购买成功，规格/系统正确，可以进入终端。
- 知道最终付款金额、到期日期和续费方式。
- 进入下一章，尚未把任何密钥写入GitHub。
