# 03 · 配置与功能命令

真实配置在服务器`/opt/qq-deepseek/config.json`，模板在`config/config.example.json`。不要把真实文件上传仓库。

## 配置字段

| 字段 | 说明 |
|---|---|
| qq | 机器人QQ，字符串 |
| owner_qq | 主人QQ，用于签名/空间管理与余额提醒收件人 |
| api_key | DeepSeek官方Key，隐藏输入 |
| onebot_token | 自动生成的OneBot凭据；网关两条HTTP连接用同一个值 |
| model | 默认deepseek-flash，可用性以官方模型列表为准 |
| allowed_private_users | 允许私聊的账号字符串列表；主人必须在内 |
| allowed_groups | 允许群号列表；机器人还需实际在群内 |
| allow_self_commands | 默认false；允许机器人自身私聊命令时开启 |
| daily_group_limit | 每个会话每日模型/指令回复额度，默认100；戳一戳另有冷却 |
| web_search_enabled | 默认true，模型按需搜索；群内随机冒泡不搜索 |
| ambient_groups | 可选群聊低频参与配置，默认空对象 |

低频群聊示例，号码是占位值：

```json
{
  "ambient_groups": {
    "1000000003": {"enabled": true, "probability": 0.12, "cooldown_seconds": 180}
  }
}
```

将该群同时加入`allowed_groups`。普通群消息才参与抽样；@、叫名字、已识别的引用和短时承接优先。这里的主动接话依赖群里有新消息，不是无消息时定时刷屏。

## 公开命令

| 指令/动作 | 行为 |
|---|---|
| /功能、/帮助、/help | 查看菜单 |
| /状态 | 当前模型、联网、思考、表情包等状态 |
| /表情 | 列出可用图片键 |
| /清空、/reset | 删除当前会话历史；不会切换人设 |
| /深度思考 开启 | 当前会话后续调用开启模型思考 |
| /深度思考 关闭 | 恢复普通模式 |
| /深度思考 状态 | 查询本会话状态 |
| 双击头像 | 戳一戳回应；同会话30秒冷却 |
| “发个加油表情” | 由模型选择图片标记，受表情频率限制 |

深度思考按“会话×提问者”隔离并保存，不会由一个群友改变全群或其他私聊。默认关闭，开启会增加模型等待与额度消耗。思考过程不发送到QQ。

## 主人私聊命令

| 指令 | 示例与限制 |
|---|---|
| /余额、查询余额 | 主人或机器人自身的已授权私聊可查；群里不公开 |
| /签名 内容 | 1–80字，直接提交签名修改 |
| /签名草稿 主题 | 生成建议，不写入签名 |
| /说说 内容、/空间 内容 | 1–1500字，发布说说，默认所有人可见 |
| /图文 cheer 内容 | 搭配memes白名单图片发布说说 |
| /说说草稿 主题 | 生成文案，不发布，不引用私人聊天历史 |
| /近期说说 | 读取机器人自己的原生空间列表前5条 |

写入类操作同类间隔60秒、每日各最多10次；相同内容24小时内不重复提交。超时不自动重发，先去QQ/空间确认，避免重复发布。当前没有通用删除空间说说命令；需要删除时在QQ官方界面操作。

## 自身提问

开启`allow_self_commands`、`reportSelfMessage`并把机器人QQ加入私聊白名单后：

- 机器人给自己发普通问句可触发。
- 机器人向已授权私聊对象发`/ai 你的问题`可触发。
- 普通已发回复不会循环触发；程序同时记录自己发送的分条文本以防回环。

## 头像、昵称与固定人设

头像和昵称由账号持有人在QQ资料页设置，也可由已有管理工具处理；本项目没有开放给群友的昵称、头像或人设修改指令。

运行时固定人设在`bot.py`的`PERSONA_TEXT`及`PERSONA_EXAMPLES`。`persona.txt`和`persona-card.json`只是备份展示，修改它们不会自动改运行时人设。需要改代码人设时，先测试再用安装脚本更新；聊天输入不能写入源码。

## 表情包

8张图片位于`memes/`，键为happy、confused、received、sleepy、sad、giggle、relax、cheer。`catalog.json`用label和file描述。仅允许目录内的PNG/JPG/GIF/WebP，不接受模型任意给出的路径或URL。更新目录后运行时会读取，无需为新增图片专门重启。
